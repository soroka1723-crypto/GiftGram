# GiftGram — Android

**GiftGram** — приватная сборка мессенджера для Android: общайся, ищи друзей, продавай
и делай что хочешь. Нативный Android-клиент с брендингом GiftGram, тёмной темой
и собственным меню приложения.

📢 Канал с информацией и обновлениями: **https://t.me/Giftgrammmmmm**

---

## Что это

Нативное Android-приложение (`com.giftgram.messenger`), которое запускает движок
Telegram Web (клиент K) внутри собственного клиента GiftGram. Вы получаете привычные
чаты, каналы, группы, медиа и возможность продавать — в приложении со своим именем,
иконкой, сплэшем, темой и меню.

Это **приватная сборка**: подписана собственным ключом, не публикуется в Google Play,
`applicationId` и имя приложения — свои.

## Возможности

| Раздел | Что делает |
|---|---|
| 💬 Чаты | Полноценный клиент: личные чаты, группы, каналы, медиа |
| 👥 Поиск друзей | Поиск людей по имени и `@username`, переход по ссылкам `t.me` |
| 🛒 Продажи | Витрины, каналы и сделки прямо в переписке |
| 📎 Файлы | Загрузка вложений (фото, видео, документы) из системного проводника |
| ⬇️ Скачивание | Сохранение файлов в «Загрузки»; поддержка `blob:`-ссылок через JS-мост |
| 🎤 Медиа | Разрешения камеры/микрофона для звонков и голосовых |
| 🌙 Темы | Тёмная (по умолчанию) и светлая, переключаются в меню |
| 📶 Офлайн | Экран «Нет подключения» с кнопкой повтора |
| 🔗 Deep links | Ссылки `t.me/...` открываются прямо в GiftGram |
| 🧹 Приватность | Очистка кэша, cookies и WebStorage одной кнопкой |

## Требования для сборки

- JDK 17
- Android SDK: `platforms;android-35`, `build-tools;35.0.0`
- Gradle 8.9 (wrapper уже в репозитории)

## Сборка

```bash
# 1. Указать путь к Android SDK
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# 2. Собрать release APK
./gradlew assembleRelease

# 3. Результат
# app/build/outputs/apk/release/app-release.apk
```

Отладочная сборка:

```bash
./gradlew assembleDebug
```

## Подпись

Приватная сборка подписывается ключом `keystore/giftgram.jks`
(alias `giftgram`, RSA 4096, срок 30 лет). Параметры подписи заданы в
`app/build.gradle` в блоке `signingConfigs.release`.

> Для реального использования замените пароль и ключ на свои и не храните
> их в открытом репозитории.

## Установка на устройство

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

Или скопируйте APK на телефон и откройте его (потребуется разрешить установку
из неизвестных источников).

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | Работа мессенджера, проверка связи |
| `CAMERA`, `RECORD_AUDIO` | Звонки, видеосообщения, голосовые |
| `ACCESS_FINE_LOCATION` | Отправка геолокации |
| `POST_NOTIFICATIONS` | Уведомления (Android 13+) |
| `READ_MEDIA_*` | Выбор фото, видео и аудио для отправки |
